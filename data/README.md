# Data

The project uses IBM's public **Telco Customer Churn** dataset.

The raw CSV is intentionally not committed to this repository. The notebooks download it automatically from:

https://raw.githubusercontent.com/IBM/telco-customer-churn-on-icp4d/master/data/Telco-Customer-Churn.csv

Expected local filename:

`Telco-Customer-Churn.csv`

Keeping the dataset out of Git makes the repository lighter and avoids redistributing a third-party dataset without checking its current terms.
