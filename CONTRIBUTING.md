# Contributing

Thanks for taking an interest in this project.

## Getting started

1. Fork the repository.
2. Create a feature branch.
3. Install the dependencies from `requirements.txt`.
4. Run the notebooks from the beginning so the model artifacts are generated consistently.
5. Test the Flask application locally.
6. Keep notebook cells readable and explain non-obvious decisions with short comments.

## Pull requests

Please keep pull requests focused. Include a short description of what changed and, when relevant, mention changes to model metrics, SHAP explanations or the web application.

## Code style

Prefer clear Python and straightforward variable names. Avoid introducing a large framework or a new module when a small change to the existing notebook or Flask application is sufficient.

## Dataset and privacy

Do not commit private customer data. Use the public dataset described in `data/README.md`.
